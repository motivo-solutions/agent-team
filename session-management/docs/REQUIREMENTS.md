# セッション管理モジュール — 要件定義書

## 概要

本モジュールは、エージェント構成と各メンバーに割り当てられたペインの対応関係を受け取り、指定された各ペインに対してエージェント（CLI プロセス）を起動・復旧する責務を持つ。ペイン配置や通信基盤の管理は関心外であり、それらは上位・他モジュールの責務として扱う。

## 前提条件

- リーダーは Claude Code のセッション上で動作していること
- 対象とするペインが、呼び出し元により既に作成されていること
- 各メンバーに適用する設定（CLI 種別・起動オプション・role prompt のパス等）が agents 構成として与えられること
- tmux セッション内で対象ペインに対して入力送信が可能であること

## 業務要件

AI 開発チームの起動・復旧フェーズにおいて、呼び出し元（チーム管理モジュール等）が「どのメンバーをどのペインで動作させるか」を決めたのち、その決定に従って実際にエージェントを立ち上げる・あるいは既に立ち上がっているエージェントを再利用する処理が必要になる。この責務を一箇所に集約することで、呼び出し元は pane 作成と高レベルなオーケストレーションに集中でき、エージェントの起動手順の変更が他モジュールへ波及しない。

## 機能要件

### エージェント起動（FR-SM1）

- **FR-SM1.1**: 呼び出し元から与えられたエージェント構成と、`member → pane_id` の対応を受け取り、各メンバーのエージェントを対応するペインで起動できること
- **FR-SM1.2**: エージェント構成に起動不要として表現されたメンバー（例: リーダー本人）は起動対象から除外できること
- **FR-SM1.3**: 各メンバーに対する起動モード・適用する役割定義・モデル等の設定は、エージェント構成に記述された値をそのまま反映できること。本モジュールは特定メンバーの設定をハードコードしない

### エージェント復旧（FR-SM2）

- **FR-SM2.1**: 呼び出し元から与えられたエージェント構成と `member → pane_id` の対応を受け取り、各メンバーのエージェントを対応するペインで resume 起動できること
- **FR-SM2.2**: resume 起動は、各 CLI が提供するセッション再開機能を利用して、前回の会話コンテキストを引き継ぐ形でエージェントを立ち上げること
- **FR-SM2.3**: 復旧は基本的に対象メンバーのエージェントが全て停止している状態で呼ばれる前提とし、該当する停止中メンバーを一括で resume 起動すること
- **FR-SM2.4**: 起動対象外のメンバー（`launcher` を持たないメンバー。例: リーダー本人）は復旧対象からも除外すること

### 運用（FR-SM3）

- **FR-SM3.1**: インストールスクリプトにより、本モジュールのスクリプトをプロジェクトに配置できること
- **FR-SM3.2**: アンインストールスクリプトにより、インストールで配置したファイルをプロジェクトから除去できること

## 非機能要件

### 冪等性

- **NFR-SM1.1**: 復旧処理を繰り返し呼び出しても、また復旧対象に動作中のメンバーが混在していても、動作中のエージェントに副作用を与えないこと。動作中と判定したメンバーは対象外としてスキップし、既存のセッションを維持すること

### 汎用性

- **NFR-SM2.1**: 特定のメンバー構成・特定の CLI・特定のチーム編成に依存しないこと
- **NFR-SM2.2**: 呼び出し元がエージェント構成を差し替えるだけで、対応可能な CLI 種別や起動オプションを追加・変更できること

### 信頼性

- **NFR-SM3.1**: 一部メンバーの起動に失敗しても、他メンバーの起動結果を呼び出し元が判別できること
